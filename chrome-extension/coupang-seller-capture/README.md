# 쿠팡 판매자정보 캡처

쿠팡 상품페이지의 "판매자 정보"(상호/대표자, 사업장 소재지, e-mail, 연락처, 통신판매업 신고번호, 사업자번호, 구매안전서비스)를 캡처해서 브라우저에 누적 저장하고, CSV(엑셀) 파일로 다운로드하는 크롬 확장프로그램입니다.

## 설치 방법 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions` 입력 후 이동
2. 우측 상단 "개발자 모드" 토글 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(`chrome-extension/coupang-seller-capture`)를 선택

설치 후 툴바에 확장프로그램 아이콘이 나타납니다. 필요하면 핀 아이콘을 눌러 고정하세요.

## 사용 방법 1 — 상품페이지 1개씩 캡처 (차단 위험이 가장 적은 방법, 추천)

이 방법은 페이지 이동을 전부 사람이 직접 클릭해서 하기 때문에, 쿠팡 입장에서는 그냥 평범하게 쇼핑하는 사용자와 다르지 않습니다. 자동 캡처 기능들이 차단에 걸린 뒤라면, 당분간은 이 방법을 쓰는 걸 권장합니다.

**버튼으로 캡처**
1. 쿠팡 상품페이지에서 "배송/교환/반품 안내" 탭을 열어 "판매자 정보"가 화면에 보이도록 합니다.
2. 확장프로그램 아이콘 클릭 → "이 페이지에서 판매자정보 캡처" 버튼 클릭
3. 캡처된 항목은 팝업 목록에 누적되며, 브라우저에 계속 저장됩니다.

**단축키로 더 빠르게 캡처 (팝업을 열 필요 없음)**
1. 평소처럼 쿠팡에서 상품을 클릭해(또는 여러 상품을 중클릭/Ctrl+클릭으로 새 탭에 열어) 둘러봅니다.
2. 상품페이지에서 `Alt+Shift+K`를 누르면, "배송/교환/반품 안내" 탭이 안 열려 있어도 자동으로 한 번 클릭을 시도한 뒤 즉시 캡처합니다.
3. 확장프로그램 아이콘에 초록색 "OK"가 잠깐 뜨면 성공, 빨간색 "X"가 뜨면 실패(판매자 정보를 못 찾음)입니다.
4. 단축키는 `chrome://extensions/shortcuts`에서 원하는 키 조합으로 바꿀 수 있습니다. (`Ctrl+Shift+C`처럼 크롬 개발자도구가 이미 쓰는 조합은 피해주세요 — 확장프로그램에 전달되지 않고 크롬이 먼저 가로챕니다.)

**여러 탭을 한 번에 — "열려있는 쿠팡 상품 탭 모두 캡처" (가장 안전, 추천)**
1. 평소처럼 쿠팡에서 관심 있는 상품들을 중클릭/Ctrl+클릭으로 여러 개 새 탭에 엽니다. (직접 클릭한 것이므로 몇 개를 열든 문제 없습니다.)
2. 확장프로그램 아이콘 클릭 → "열려있는 쿠팡 상품 탭 모두 캡처" 버튼 클릭
3. 찾은 상품 탭 개수를 보여주는 확인창에서 "확인"을 누르면, 이미 열려있는 탭들을 순서대로 읽어 판매자정보를 캡처합니다.
4. 이 방법은 **이 확장프로그램이 새로 페이지를 열거나 쿠팡에 요청을 보내지 않습니다** — 이미 사람이 열어둔 탭의 화면 내용을 읽기만 하므로, 세 방법 중 차단 위험이 가장 낮습니다.

이 방식들은 사람이 직접 여러 탭을 넘기며 확인하는 것과 동일한 접근 패턴이라, 아래 자동 캡처 기능들보다 훨씬 안전합니다.

## 사용 방법 2 — 검색/카테고리 목록 페이지에서 자동 캡처 (차단 위험 있음)

1. 쿠팡 검색결과 또는 카테고리 목록 페이지(예: "컴퓨터책상" 검색 결과처럼 상품이 여러 개 나열된 화면)를 엽니다.
2. 확장프로그램 아이콘 클릭 → "자동 캡처 시작" 버튼 클릭
3. 찾은 상품 개수를 보여주는 확인창이 뜨면 "확인"을 누릅니다. (한 번에 최대 30개)
4. 화면에 보이는 상품을 순서대로 백그라운드 탭에서 열어 "배송/교환/반품 안내" 탭을 자동으로 클릭하고 판매자 정보를 캡처합니다. 상품당 약 7~8초의 여유를 두고 진행하며(쿠팡에 부담을 주지 않기 위해 일부러 느리게 동작합니다), 팝업을 닫아도 계속됩니다.
5. 진행 중 다시 팝업을 열면 진행 상황("n / 총개수 캡처 중...")이 표시됩니다. 중간에 멈추고 싶으면 "중지" 버튼을 누르세요. 처리 중이던 상품 하나가 끝나는 즉시(보통 몇 초 이내) 멈춥니다.

## 사용 방법 3 — 키워드 여러 개로 자동 수집 (차단 위험 있음)

1. 확장프로그램 아이콘 클릭 (어떤 페이지에 있든 상관없습니다. 내부적으로 쿠팡 검색 탭을 직접 엽니다)
2. "키워드로 자동 수집" 칸에 키워드를 한 줄에 하나씩 입력 (최대 50개)
3. "키워드당 수집 개수"를 정합니다 (기본 30, 최대 30). 먼저 키워드 몇 개 × 개수 적게로 테스트해보고, 문제없으면 늘리는 걸 추천합니다.
4. "키워드 자동 수집 시작" 클릭 → 예상 소요 시간이 표시되는 확인창에서 "확인"
5. 키워드마다 쿠팡 검색 결과를 열어 상위 상품 링크를 모으고, 그 상품들을 순서대로 캡처합니다. 진행 상황에 "키워드 n/전체 · 상품 n/전체"가 표시됩니다.

키워드 50개 × 30개처럼 큰 규모는 여유 있게 진행해도 여러 시간이 걸릴 수 있습니다. 처음에는 키워드 5개 정도, 키워드당 5~10개로 작게 시작해서 잘 도는지 확인한 뒤 규모를 늘리는 걸 권장합니다.

**로켓 배지 상품만 필터링**: "상품목록 자동 캡처"와 "키워드로 자동 수집" 위에 있는 "로켓 배지 상품만 수집" 체크박스를 켜면, 검색 결과 페이지에 쿠팡 자체의 "판매자로켓" 필터가 있을 경우 그걸 먼저 자동으로 클릭해 정확하게 걸러낸 뒤 수집합니다. (그 필터가 안 보이는 페이지에서는, 화면에 표시된 "로켓" 관련 배지 텍스트를 직접 스캔하는 방식으로 대신합니다.) 새로운 자동화를 추가하는 게 아니라 기존 두 기능이 대상으로 삼는 상품 범위만 좁히는 것이라 차단 위험은 그대로입니다(더 늘지도, 줄지도 않습니다).

캡처된 전체 목록은 세 방식 모두 하나의 저장소에 함께 쌓이며, CSV에는 "검색키워드" 컬럼이 추가되어 어떤 키워드로 수집됐는지 구분할 수 있습니다(상품페이지 1개씩 캡처나 목록 자동 캡처로 모은 항목은 이 칸이 비어 있습니다).

## 공통 사용법

- 필요할 때 "CSV 다운로드" 버튼을 눌러 지금까지 캡처한 전체 목록을 엑셀에서 열 수 있는 CSV 파일로 저장합니다.
- 개별 항목은 목록에서 "삭제", 전체 초기화는 "전체 삭제" 버튼을 사용합니다.
- **중복은 자동으로 걸러집니다.** 같은 상품(정확히는 같은 판매자의 같은 상품 offer, `vendorItemId` 기준)을 다시 캡처하면 새로 추가되지 않고 건너뜁니다 — 같은 상품이 여러 키워드 검색에 걸쳐 나오거나, 같은 탭을 실수로 두 번 캡처해도 CSV에 중복 행이 쌓이지 않습니다. 단축키로 이미 캡처된 상품을 다시 누르면 아이콘에 주황색 "DUP"가 표시됩니다.
- **이 업데이트 이전에 캡처해서 이미 중복이 쌓인 목록이 있다면**, "중복 정리" 버튼으로 한 번에 정리할 수 있습니다. 몇 건이 제거될지 보여주는 확인창이 뜬 뒤 정리됩니다.

## 참고

- 쿠팡 페이지 구조가 바뀌어도 잘 동작하도록, 특정 CSS 클래스명이 아닌 화면에 보이는 라벨 텍스트("상호/대표자", "사업장 소재지" 등)를 기준으로 값을 찾습니다.
- 저장된 데이터는 이 브라우저(크롬 프로필)의 로컬 저장소에만 보관되며, 외부로 전송되지 않습니다.
- "판매자 정보" 영역이 화면에 로드되어 있지 않으면 캡처에 실패할 수 있습니다. 이 경우 "배송/교환/반품 안내" 탭을 펼친 뒤 다시 시도하세요. 자동 캡처는 이 탭 클릭도 자동으로 시도합니다.
- 자동 캡처는 쿠팡 서버에 부담을 주지 않도록 한 번에 최대 30개, 상품/키워드 사이에 여유 있는(무작위성이 섞인) 딜레이를 두고 순서대로(동시에 여러 개 열지 않고) 처리합니다. 너무 자주 반복 실행하지 않는 것을 권장합니다.
- **차단 화면을 만나면 이 확장프로그램은 남은 작업을 억지로 계속하지 않고 그 즉시 전체 작업을 멈춥니다.** 감지하는 차단 화면은 두 가지입니다: 쿠팡 자체의 "요청하신 페이지의 사용권한이 없습니다", 그리고 쿠팡이 쓰는 CDN(Akamai)이 요청을 아예 서버까지 보내지 않고 더 앞단에서 막는 "Access Denied / You don't have permission to access..." 화면(주소에 `errors.edgesuite.net`이 보이는 경우)입니다. 팝업에 안내 문구가 뜨면 몇 시간 정도(가능하면 하루) 완전히 쉬었다가, 다시 시작할 때는 이전에 쓰던 개수보다 훨씬 더 작게(키워드 1~2개, 상품 3~5개 수준) 테스트해서 차단이 풀렸는지부터 확인해주세요. 같은 세션에서 바로 재시도하면 또 막힐 가능성이 높습니다. IP나 계정(크롬 프로필)을 바꿔가며 이 차단을 우회하는 기능은 의도적으로 넣지 않았습니다.
- 이번 업데이트로 권한이 늘어났습니다(탭 열기/닫기, 쿠팡 사이트 접근). `chrome://extensions`에서 확장프로그램을 새로고침(🔄)해 최신 코드를 반영해주세요.
- 크롬은 오래 대기 중인 확장프로그램을 자체적으로 잠깐 재시작시킬 수 있습니다. 이 경우 진행률이 갑자기 멈춘 것처럼 보일 수 있는데, 팝업을 닫았다 다시 열면 "중단됨" 상태로 자동 정리됩니다 — 그때까지 캡처된 항목은 그대로 저장되어 있으니 필요하면 자동 캡처를 다시 시작하세요.

# 쿠팡 판매자정보 캡처

쿠팡 상품페이지의 "판매자 정보"(상호/대표자, 사업장 소재지, e-mail, 연락처, 통신판매업 신고번호, 사업자번호, 구매안전서비스)를 캡처해서 브라우저에 누적 저장하고, CSV(엑셀) 파일로 다운로드하는 크롬 확장프로그램입니다.

## 설치 방법 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions` 입력 후 이동
2. 우측 상단 "개발자 모드" 토글 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(`chrome-extension/coupang-seller-capture`)를 선택

설치 후 툴바에 확장프로그램 아이콘이 나타납니다. 필요하면 핀 아이콘을 눌러 고정하세요.

## 사용 방법 1 — 상품페이지 1개씩 캡처

1. 쿠팡 상품페이지에서 "배송/교환/반품 안내" 탭을 열어 "판매자 정보"가 화면에 보이도록 합니다.
2. 확장프로그램 아이콘 클릭 → "이 페이지에서 판매자정보 캡처" 버튼 클릭
3. 캡처된 항목은 팝업 목록에 누적되며, 브라우저에 계속 저장됩니다.

## 사용 방법 2 — 검색/카테고리 목록 페이지에서 자동 캡처

1. 쿠팡 검색결과 또는 카테고리 목록 페이지(예: "컴퓨터책상" 검색 결과처럼 상품이 여러 개 나열된 화면)를 엽니다.
2. 확장프로그램 아이콘 클릭 → "자동 캡처 시작" 버튼 클릭
3. 찾은 상품 개수를 보여주는 확인창이 뜨면 "확인"을 누릅니다. (한 번에 최대 30개)
4. 화면에 보이는 상품을 순서대로 백그라운드 탭에서 열어 "배송/교환/반품 안내" 탭을 자동으로 클릭하고 판매자 정보를 캡처합니다. 상품당 약 2~3초가 걸리며, 팝업을 닫아도 계속 진행됩니다.
5. 진행 중 다시 팝업을 열면 진행 상황("n / 총개수 캡처 중...")이 표시됩니다. 중간에 멈추고 싶으면 "중지" 버튼을 누르세요.

캡처된 전체 목록은 두 방식 모두 하나의 저장소에 함께 쌓입니다.

## 공통 사용법

- 필요할 때 "CSV 다운로드" 버튼을 눌러 지금까지 캡처한 전체 목록을 엑셀에서 열 수 있는 CSV 파일로 저장합니다.
- 개별 항목은 목록에서 "삭제", 전체 초기화는 "전체 삭제" 버튼을 사용합니다.

## 참고

- 쿠팡 페이지 구조가 바뀌어도 잘 동작하도록, 특정 CSS 클래스명이 아닌 화면에 보이는 라벨 텍스트("상호/대표자", "사업장 소재지" 등)를 기준으로 값을 찾습니다.
- 저장된 데이터는 이 브라우저(크롬 프로필)의 로컬 저장소에만 보관되며, 외부로 전송되지 않습니다.
- "판매자 정보" 영역이 화면에 로드되어 있지 않으면 캡처에 실패할 수 있습니다. 이 경우 "배송/교환/반품 안내" 탭을 펼친 뒤 다시 시도하세요. 자동 캡처는 이 탭 클릭도 자동으로 시도합니다.
- 자동 캡처는 쿠팡 서버에 부담을 주지 않도록 한 번에 최대 30개, 상품 사이에 약간의 딜레이를 두고 순서대로(동시에 여러 개 열지 않고) 처리합니다. 너무 자주 반복 실행하지 않는 것을 권장합니다.
- 이번 업데이트로 권한이 늘어났습니다(탭 열기/닫기, 쿠팡 사이트 접근). `chrome://extensions`에서 확장프로그램을 새로고침(🔄)해 최신 코드를 반영해주세요.

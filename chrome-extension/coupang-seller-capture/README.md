# 쿠팡 판매자정보 캡처

쿠팡 상품페이지의 "판매자 정보"(상호/대표자, 사업장 소재지, e-mail, 연락처, 통신판매업 신고번호, 사업자번호, 구매안전서비스)를 캡처해서 브라우저에 누적 저장하고, CSV(엑셀) 파일로 다운로드하거나 구글 스프레드시트에 실시간으로 올리는 크롬 확장프로그램입니다.

## 설치 방법 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions` 입력 후 이동
2. 우측 상단 "개발자 모드" 토글 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(`chrome-extension/coupang-seller-capture`)를 선택

설치 후 툴바에 확장프로그램 아이콘이 나타납니다. 필요하면 핀 아이콘을 눌러 고정하세요.

## 사용 방법 1 — 상품페이지 1개씩 캡처 (차단 위험이 가장 적은 방법, 추천)

이 방법은 페이지 이동을 전부 사람이 직접 클릭해서 하기 때문에, 쿠팡 입장에서는 그냥 평범하게 쇼핑하는 사용자와 다르지 않습니다. 자동 캡처 기능들이 차단에 걸린 뒤라면, 당분간은 이 방법을 쓰는 걸 권장합니다.

**버튼으로 캡처**
1. 쿠팡 상품페이지에서 "배송/교환/반품 안내" 탭을 열어 "판매자 정보"가 화면에 보이도록 합니다.
2. 확장프로그램 아이콘 클릭 → "이 페이지에서 판매자정보 캡처" 버튼 클릭
3. 캡처된 항목은 팝업 목록에 누적되며, 브라우저에 계속 저장됩니다.

**단축키로 더 빠르게 캡처 (팝업을 열 필요 없음)**
1. 평소처럼 쿠팡에서 상품을 클릭해(또는 여러 상품을 중클릭/Ctrl+클릭으로 새 탭에 열어) 둘러봅니다.
2. 상품페이지에서 `Alt+Shift+K`를 누르면, "배송/교환/반품 안내" 탭이 안 열려 있어도 자동으로 한 번 클릭을 시도한 뒤 즉시 캡처합니다.
3. 확장프로그램 아이콘에 초록색 "OK"가 잠깐 뜨면 성공, 빨간색 "X"가 뜨면 실패(판매자 정보를 못 찾음)입니다.
4. 단축키는 `chrome://extensions/shortcuts`에서 원하는 키 조합으로 바꿀 수 있습니다. (`Ctrl+Shift+C`처럼 크롬 개발자도구가 이미 쓰는 조합은 피해주세요 — 확장프로그램에 전달되지 않고 크롬이 먼저 가로챕니다.)

**여러 탭을 한 번에 — "열려있는 쿠팡 상품 탭 모두 캡처" (가장 안전, 추천)**
1. 평소처럼 쿠팡에서 관심 있는 상품들을 중클릭/Ctrl+클릭으로 여러 개 새 탭에 엽니다. (직접 클릭한 것이므로 몇 개를 열든 문제 없습니다.)
2. 확장프로그램 아이콘 클릭 → "열려있는 쿠팡 상품 탭 모두 캡처" 버튼 클릭
3. 찾은 상품 탭 개수를 보여주는 확인창에서 "확인"을 누르면, 이미 열려있는 탭들을 순서대로 읽어 판매자정보를 캡처합니다.
4. 이 방법은 **이 확장프로그램이 새로 페이지를 열거나 쿠팡에 요청을 보내지 않습니다** — 이미 사람이 열어둔 탭의 화면 내용을 읽기만 하므로, 세 방법 중 차단 위험이 가장 낮습니다.

이 방식들은 사람이 직접 여러 탭을 넘기며 확인하는 것과 동일한 접근 패턴이라, 아래 자동 캡처 기능들보다 훨씬 안전합니다.

## 사용 방법 2 — 검색/카테고리 목록 페이지에서 자동 캡처 (차단 위험 있음)

1. 쿠팡 검색결과 또는 카테고리 목록 페이지(예: "컴퓨터책상" 검색 결과처럼 상품이 여러 개 나열된 화면)를 엽니다.
2. 확장프로그램 아이콘 클릭 → "자동 캡처 시작" 버튼 클릭
3. 찾은 상품 개수를 보여주는 확인창이 뜨면 "확인"을 누릅니다. (한 번에 최대 30개)
4. 화면에 보이는 상품을 **한 번에 한 개씩만** 백그라운드 탭에서 열어 "배송/교환/반품 안내" 탭을 자동으로 클릭하고 판매자 정보를 캡처한 뒤 그 탭을 닫고, 다음 상품으로 넘어갑니다 — 여러 탭을 한꺼번에 띄워두지 않습니다. 상품 사이 대기시간은 "로켓 배지 상품만 수집" 체크박스 옆의 **"상품 사이 대기시간(초)"**로 직접 조절할 수 있습니다(기본 10초, 최소 3초 ~ 최대 120초) — 예전에 차단을 겪으셨다면 이 값을 20~30초 이상으로 늘려보세요. 팝업을 닫아도 계속됩니다.
5. 진행 중 다시 팝업을 열면 진행 상황("n / 총개수 캡처 중...")이 표시됩니다. 중간에 멈추고 싶으면 "중지" 버튼을 누르세요. 처리 중이던 상품 하나가 끝나는 즉시(보통 몇 초 이내) 멈춥니다.

## 사용 방법 3 — 키워드 여러 개로 자동 수집 (차단 위험 있음)

1. 확장프로그램 아이콘 클릭 (어떤 페이지에 있든 상관없습니다. 내부적으로 검색 탭을 직접 엽니다)
2. **검색 대상**을 고릅니다 — "일반 검색(np/search)"은 평소 쿠팡 검색결과 페이지, "판매자특가(np/omp)"는 "쿠팡 판매자특가" 행사 페이지(`coupang.com/np/omp`) 안의 자체 검색창을 대상으로 합니다.
3. "키워드로 자동 수집" 칸에 키워드를 한 줄에 하나씩 입력 (최대 50개)
4. "키워드당 수집 개수"를 정합니다 (기본 30, 최대 30). 먼저 키워드 몇 개 × 개수 적게로 테스트해보고, 문제없으면 늘리는 걸 추천합니다.
5. "키워드 자동 수집 시작" 클릭 → 예상 소요 시간이 표시되는 확인창에서 "확인"
6. 키워드마다 검색 결과를 열어 상위 상품 링크를 모으고, 그 상품들을 순서대로 캡처합니다. 진행 상황에 "키워드 n/전체 · 상품 n/전체"가 표시됩니다.

키워드 50개 × 30개처럼 큰 규모는 여유 있게 진행해도 여러 시간이 걸릴 수 있습니다. 처음에는 키워드 5개 정도, 키워드당 5~10개로 작게 시작해서 잘 도는지 확인한 뒤 규모를 늘리는 걸 권장합니다.

이 기능도 "상품 사이 대기시간(초)" 설정을 그대로 따라, 한 번에 상품 탭을 한 개씩만 열고 그 사이사이 지정한 만큼 쉽니다.

**"판매자특가(np/omp)" 선택 시 참고**: 이 페이지는 검색해도 주소창 URL이 바뀌지 않는 방식이라(일반 검색결과처럼 `?q=키워드`로 바로 열 수가 없음), 그 페이지 안의 검색창을 코드로 직접 찾아서 키워드를 입력하고 엔터를 누르는 방식으로 동작합니다. 쿠팡이 이 페이지의 화면 구성을 바꾸면 검색창을 못 찾을 수 있는데, 이 경우 해당 키워드는 조용히 건너뛰고 다음 키워드로 넘어갑니다(진행 상황의 "키워드 n/전체"는 그래도 올라갑니다). 특정 키워드에서 결과가 하나도 안 잡히는 게 반복되면, 먼저 `coupang.com/np/omp`를 직접 열어 검색창이 화면 어디 있는지, 레이아웃이 바뀌지 않았는지 확인해보세요.

만약 이미 그 페이지에서 직접 검색해서 원하는 결과를 보고 있는 상태라면, 굳이 이 "키워드 자동 수집"을 쓸 필요 없이 **"사용 방법 2 — 검색/카테고리 목록 페이지에서 자동 캡처"**(현재 화면에 보이는 상품을 그대로 캡처)를 바로 써도 됩니다 — 그쪽은 페이지 종류를 가리지 않아 더 간단하고 안전합니다.

### 상품 탭만 순서대로 열기 (캡처는 안 함 — 더 안전)

"키워드 자동 수집 시작" 버튼은 각 상품을 열어 정보까지 자동으로 캡처하고 탭을 바로 닫습니다. 대신 **탭을 열기만 하고 아무 것도 자동으로 하지 않길 원하면** 같은 자리의 **"키워드로 상품 탭만 순서대로 열기"** 버튼을 쓰세요.

- 검색 대상/키워드/키워드당 개수/로켓 필터/상품 사이 대기시간은 위 "키워드 자동 수집"과 똑같이 적용됩니다.
- 각 상품을 새 탭으로 하나씩 열기만 하고, 탭을 닫지도 않고 판매자정보를 캡처하지도 않습니다 — 열린 탭은 그대로 브라우저에 쌓입니다.
- 다 열리고 나면, **"열려있는 쿠팡 상품 탭 모두 캡처"** 버튼으로 그 탭들을 한 번에 캡처하세요. 이 버튼은 이미 열려있는 탭을 읽기만 할 뿐 새로 페이지를 요청하지 않아서, 세 가지 자동화 방식 중 가장 안전합니다.
- 탭을 여러 개 열어두고 쓰는 방식이라, 한 번에 너무 많이 열어두면 브라우저가 느려지거나 관리하기 번거로울 수 있습니다. 키워드당 개수를 적당히(5~10개 정도) 잡는 걸 권장합니다.

**로켓 배지 상품만 필터링**: "상품목록 자동 캡처"와 "키워드로 자동 수집" 위에 있는 "로켓 배지 상품만 수집" 체크박스를 켜면, 검색 결과 페이지에 쿠팡 자체의 "판매자로켓" 필터가 있을 경우 그걸 먼저 자동으로 클릭해 정확하게 걸러낸 뒤 수집합니다. (그 필터가 안 보이는 페이지에서는, 화면에 표시된 "로켓" 관련 배지 텍스트를 직접 스캔하는 방식으로 대신합니다.) 새로운 자동화를 추가하는 게 아니라 기존 두 기능이 대상으로 삼는 상품 범위만 좁히는 것이라 차단 위험은 그대로입니다(더 늘지도, 줄지도 않습니다).

캡처된 전체 목록은 세 방식 모두 하나의 저장소에 함께 쌓이며, CSV에는 "검색키워드" 컬럼이 추가되어 어떤 키워드로 수집됐는지 구분할 수 있습니다(상품페이지 1개씩 캡처나 목록 자동 캡처로 모은 항목은 이 칸이 비어 있습니다).

## 공통 사용법

- 필요할 때 "CSV 다운로드" 버튼을 눌러 지금까지 캡처한 전체 목록을 엑셀에서 열 수 있는 CSV 파일로 저장합니다.
- 개별 항목은 목록에서 "삭제", 전체 초기화는 "전체 삭제" 버튼을 사용합니다.
- **중복은 자동으로 걸러집니다.** 같은 상품(정확히는 같은 판매자의 같은 상품 offer, `vendorItemId` 기준)을 다시 캡처하면 새로 추가되지 않고 건너뜁니다 — 같은 상품이 여러 키워드 검색에 걸쳐 나오거나, 같은 탭을 실수로 두 번 캡처해도 CSV에 중복 행이 쌓이지 않습니다. 단축키로 이미 캡처된 상품을 다시 누르면 아이콘에 주황색 "DUP"가 표시됩니다.
- **이 업데이트 이전에 캡처해서 이미 중복이 쌓인 목록이 있다면**, "중복 정리" 버튼으로 한 번에 정리할 수 있습니다. 몇 건이 제거될지 보여주는 확인창이 뜬 뒤 정리됩니다.

## 구글 스프레드시트 실시간 연동 (선택)

설정해두면, 캡처할 때마다(단축키/버튼/자동 캡처 어떤 방식이든) 그 즉시 구글 스프레드시트에 한 줄씩 추가됩니다. 설정하지 않아도 CSV 다운로드 기능은 그대로 쓸 수 있습니다.

### 1. Apps Script 배포 (최초 1회)

**방법 A — 시트 안에서 열기 (기본, 추천)**

1. [sheets.google.com](https://sheets.google.com) 에서 데이터를 받을 스프레드시트를 새로 만들거나 엽니다. (PC 브라우저 기준입니다. 모바일 앱에서는 이 메뉴가 없습니다.)
2. 화면 맨 위, 시트 이름 아래에 있는 메뉴 줄을 봅니다: `파일 수정 보기 삽입 서식 데이터 도구 확장 프로그램 도움말` — 이 중 **확장 프로그램**을 클릭합니다.
3. 펼쳐지는 메뉴에서 **Apps Script**를 클릭합니다. 새 탭이 열리며 코드 편집기 화면이 나옵니다.
4. 기본으로 들어있는 `myFunction() {}` 같은 코드를 전체 선택(Ctrl+A) → 삭제하고, 이 폴더의 `google-apps-script/Code.gs` 파일 내용을 그대로 붙여넣습니다.
5. 좌측 상단 프로젝트 이름("제목 없는 프로젝트")을 원하는 이름으로 바꿔도 되고, 그냥 두셔도 됩니다.
6. `Ctrl+S`(또는 화면 상단 저장 아이콘 💾)로 저장합니다.

**"확장 프로그램" 메뉴가 안 보인다면** — 아래 중 하나에 해당하는지 확인해보세요.
- 크롬 등 PC용 브라우저로 접속했는지 (휴대폰 앱에는 이 기능이 없습니다)
- 열려있는 파일이 진짜 "Google 스프레드시트"인지 — 엑셀(.xlsx) 파일을 업로드해서 미리보기만 하는 상태라면 이 메뉴가 없습니다. 이 경우 **파일 → Google Sheets로 저장**을 먼저 눌러 변환하세요.
- 그래도 안 보이면 **방법 B**로 진행하세요.

**방법 B — script.google.com에서 직접 만들기 (방법 A가 안 될 때)**

1. [script.google.com](https://script.google.com) 접속 → 좌측 **+ 새 프로젝트** 클릭
2. 기본 코드를 지우고 `Code.gs` 내용을 붙여넣습니다.
3. 데이터를 받을 스프레드시트를 열어서 주소창의 URL을 봅니다: `https://docs.google.com/spreadsheets/d/이 부분이 시트 ID/edit`
4. 이 ID를 복사해서, 붙여넣은 코드 맨 위쪽의 `var SPREADSHEET_ID = "";` 따옴표 안에 넣습니다. 예: `var SPREADSHEET_ID = "1AbCd...xyz";`
5. `Ctrl+S`로 저장합니다.

**여기부터는 방법 A/B 공통입니다.**

7. 우측 상단 **배포 → 새 배포**를 클릭합니다.
8. 유형 선택 칸(톱니바퀴 아이콘) 옆에서 **웹 앱**을 선택합니다.
9. "다음 사용자로 실행": **나**, "액세스 권한이 있는 사용자": **전체**를 선택하고 **배포**를 클릭합니다.
10. 처음에는 권한 승인 화면이 뜹니다. 본인 계정이므로 "고급" → "(프로젝트명)(으)로 이동" → 허용을 눌러 승인합니다. (구글이 "확인되지 않은 앱"이라고 경고하는데, 본인이 직접 만든 스크립트이므로 정상입니다.)
11. 배포가 끝나면 "웹 앱 URL"이 표시됩니다(`https://script.google.com/macros/s/.../exec` 형태). 이 URL을 복사해둡니다.

> ⚠️ 이 URL을 아는 사람은 누구나(로그인 없이도) 이 시트에 행을 추가할 수 있습니다. 별도의 인증 단계가 없으니, URL을 공개된 곳에 올리거나 다른 사람과 공유하지 마세요. 시트 자체의 공유 설정(보기/편집 권한)은 이 URL과 별개이니 기존처럼 원하는 대로 유지하면 됩니다.

**중복 방지는 시트 쪽에서도 한 번 더 이루어집니다.** 마지막 열("상품키(중복확인용)")로 이미 들어와 있는 상품인지 확인한 뒤에만 새 행을 추가합니다 — "지금 동기화"를 여러 번 눌러도, 로컬 데이터를 지운 뒤 같은 상품을 다시 캡처해도, 같은 시트를 여러 브라우저에서 같이 써도 시트에는 중복 행이 쌓이지 않습니다.

**이미 배포해서 쓰고 있었다면 (Code.gs 업데이트)**: Apps Script 편집기에서 기존 코드를 이 파일의 최신 내용으로 다시 덮어쓰고 저장한 뒤, **배포 → 배포 관리 → (연필 아이콘) 수정 → 새 버전 → 배포**를 눌러 기존 배포를 새 버전으로 갱신하세요(URL은 그대로 유지됩니다). 첫 캡처가 들어올 때 "상품키(중복확인용)" 헤더가 자동으로 추가되니 기존 데이터는 그대로 둬도 됩니다.

### 2. 확장프로그램에 연결

1. 확장프로그램 팝업의 "구글 시트 연동" 칸에 위에서 복사한 URL을 붙여넣고 **URL 저장**을 클릭합니다.
2. 이후 캡처되는 항목은 자동으로 스프레드시트의 "판매자정보" 탭에 실시간으로 쌓입니다.
3. 네트워크 문제 등으로 일부가 못 올라갔다면, **지금 동기화** 버튼을 눌러 아직 반영 안 된 항목만 다시 보낼 수 있습니다. ("동기화 대기 중: N건"으로 표시됩니다.)
4. URL을 비워두고 저장하면 연동이 꺼지고, 로컬 저장 + CSV 다운로드만 사용하게 됩니다.

## 협업 메일 작성 도구 (선택)

캡처한 판매자 목록(엑셀)을 올리면 이메일/상품명을 읽어서 협업 제안 메일 초안을 자동으로 만들어주는 도구입니다. 확장프로그램 팝업의 **"협업 메일 작성 도구 열기"** 버튼으로 새 탭에서 엽니다.

**사용법**
1. 팝업에서 "협업 메일 작성 도구 열기" 클릭
2. "보내는 사람 정보"에 이름/직책 입력 (예: 김우연 팀장) — 템플릿의 `{{NAME}}` 자리에 들어갑니다
3. 필요하면 "메일 템플릿"의 제목/본문을 수정합니다. `{{PRODUCT}}`(상품명)와 `{{NAME}}`(보내는 사람)은 자동으로 채워집니다. 한 번 입력해두면 다음에 다른 리스트로 또 써도 그대로 남아있습니다.
4. 이 확장프로그램에서 CSV로 내보낸 엑셀(또는 이메일/상품명이 들어있는 다른 엑셀)을 업로드하거나, 아래 "스프레드시트에서 불러오기"로 구글 스프레드시트에서 직접 불러옵니다. 컬럼을 자동으로 못 찾으면 직접 골라주는 선택창이 뜹니다.
5. 목록이 뜨면 각 줄의 "상품명"이 자동으로 짧게 추출되어 채워집니다 — 어색하면 직접 수정하세요. "미리보기"로 실제 나갈 제목/본문을 확인할 수 있습니다.
6. **"Gmail로 작성하기"**를 누르면 해당 내용이 채워진 **Gmail 작성창이 새 탭으로 열립니다.** 여기서 한 번 더 확인하고 **직접 "보내기"를 눌러야** 실제로 발송됩니다 — 이 도구는 초안만 만들 뿐, 전송은 항상 사람이 직접 합니다.

- **같은 파일 안에 이메일이 중복으로 들어있으면** 업로드할 때 자동으로 걸러지고(첫 번째 것만 남김), 몇 건이 제거됐는지 상태 메시지에 표시됩니다.
- 각 줄 맨 앞의 **"완료" 체크박스**로 처리 상태를 확인할 수 있습니다. "Gmail로 작성하기"를 누르거나 자동 발송이 처리하면 자동으로 체크되고 해당 줄이 초록색으로 표시되며, 다음에 같은 파일을 다시 올려도 체크된 상태가 유지됩니다. 체크박스는 직접 클릭해서 켜거나 끌 수도 있습니다 (예: 실수로 체크된 걸 풀거나, 도구 밖에서 따로 보낸 걸 수동으로 표시할 때).

> 이메일 주소나 메일 내용은 업로드한 엑셀 파일/연동한 스프레드시트에서만 나오고, 이 확장프로그램 코드 자체에는 특정 인물의 연락처가 들어있지 않습니다.

### 구글 스프레드시트에서 불러오기 (엑셀 업로드 대신, 선택)

엑셀을 매번 다운로드/업로드하는 대신, 구글 스프레드시트를 직접 연결해 읽어올 수 있습니다. **위쪽 "구글 시트 연동"(쿠팡 캡처 자동 동기화용)과는 완전히 별개의 URL**이며, 이 메일 도구 화면에서만 쓰입니다 — 캡처 동기화용 시트를 그대로 써도 되고, 메일 발송 대상만 따로 관리하는 별도 시트를 만들어 써도 됩니다.

1. 위 "[구글 스프레드시트 실시간 연동](#구글-스프레드시트-실시간-연동-선택)"과 동일한 방법으로 대상 스프레드시트에 `google-apps-script/Code.gs`를 배포하고, 웹 앱 URL을 복사합니다. (이미 캡처 동기화용으로 배포해둔 URL을 그대로 재사용해도 됩니다.)
2. "3. 명단 가져오기" 카드의 **"구글 스프레드시트 웹 앱 URL"** 칸에 붙여넣고 **URL 저장**을 클릭합니다.
3. **"스프레드시트에서 불러오기"**를 클릭하면 해당 시트의 모든 행을 읽어와 목록에 채웁니다. 이메일/상품명 컬럼은 자동으로 인식됩니다.
4. 목록에서 **"Gmail로 작성하기"**를 누르거나 자동 발송이 항목을 처리할 때마다, 원본 스프레드시트에서 해당 행("상품키(중복확인용)" 컬럼으로 매칭)의 글자색이 **빨간색 굵게** 바뀝니다 — 시트만 보고도 누구에게 이미 메일을 보냈는지 한눈에 확인할 수 있습니다. (시트에 "상품키" 컬럼이 없는 엑셀을 올린 경우엔 이 표시는 건너뛰고, 도구 안의 "완료" 체크박스로만 표시됩니다.)

### 자동 발송 (시간당 개수 직접 지정)

아래쪽 "5. 자동 발송" 카드에서 **"시간당 발송 개수"**를 원하는 숫자로 입력하세요 (예: 10, 30). 입력한 숫자에 맞춰 간격이 자동 계산되어 바로 아래에 "약 N분 간격으로..."로 표시됩니다. **"자동 발송 시작"**을 누르면, 목록에서 아직 "Gmail로 작성하기"를 안 누른 항목들을 그 간격으로 순서대로 처리합니다.

- 크롬 자체 제약으로 최대 시간당 60건(1분 간격)까지만 가능합니다. 그보다 큰 숫자를 넣어도 60건으로 제한됩니다.
- 매번 Gmail 작성창이 **화면 앞에(포그라운드로)** 열립니다.
- 지정한 대기시간(기본 60초) 동안 상단에 배너로 카운트다운이 표시되며, **그 사이 작성창 안의 제목/본문을 직접 수정할 수 있습니다** — 시간이 다 되면 그 시점에 화면에 있는 내용 그대로 "보내기"가 자동으로 눌립니다.
- 배너의 **"지금 취소"**를 누르면 그 건은 전송되지 않고 작성창만 남습니다 (필요하면 직접 보내거나 탭을 닫으면 됩니다). **"지금 바로 전송"**을 누르면 대기시간을 건너뛰고 즉시 보냅니다.
- 팝업/이 탭을 닫아도 계속 진행됩니다 (크롬 자체의 "알람" 기능으로 동작). 진행 상황은 카드 하단에 "N / 전체건 처리됨"으로 표시됩니다.
- 중단하려면 **"자동 발송 중지"**를 누르세요. 이미 열려서 카운트다운 중이던 창은 그 자리에서 직접 취소하거나 처리해야 합니다.

> ⚠️ 이 기능은 카운트다운이 끝나면 **정말로 "보내기" 버튼을 대신 눌러줍니다.** 시작 전에 목록과 템플릿을 한 번 더 확인하세요. Gmail 화면 구성이 바뀌면 전송 버튼을 못 찾을 수 있는데, 이 경우 배너에 안내 문구가 뜨고 자동 클릭은 하지 않으니 그 창은 직접 보내면 됩니다.

### 스팸/계정 일시정지 방지

구글은 일반 Gmail 계정 기준 **하루 500통**(Workspace 유료 계정은 2,000통) 발송 한도를 공식적으로 밝히고 있지만, 시간당 한도는 공식적으로 밝히지 않습니다. 다만 경험적으로 **시간당 20통을 넘기면 스팸함 분류/계정 일시정지 위험이 크게 올라간다**고 알려져 있어, 이 도구는 아래 세 가지로 이를 반영합니다.

1. **시간당 발송 개수 경고**: "시간당 발송 개수"를 20보다 크게 입력하면 안내 문구가 주황색 경고로 바뀌고, "자동 발송 시작" 시 확인창에 위험 문구가 한 번 더 뜹니다. (막지는 않습니다 — 최종 판단은 사용자 몫입니다.)
2. **하루 최대 발송 개수**: "5. 자동 발송" 카드의 **"하루 최대 발송 개수"**(기본값 80, 권장 40~100)를 채워두면, 오늘 그 개수만큼 보낸 뒤로는 자동 발송이 그날은 더 이상 새 작성창을 열지 않고 대기합니다. **다음 날이 되면 별도 재시작 없이 같은 간격으로 자동으로 이어서 보냅니다** — 팝업/탭을 닫아둬도 크롬의 "알람"이 계속 돌면서 날짜가 바뀌는 걸 감지합니다. 0 또는 빈 칸으로 두면 하루 한도 없이 시간당 페이스로만 계속 보냅니다.
3. **제목/인사말 자동 변주**: 상품명이 겹치는 여러 줄(예: "서랍장"으로 뭉뚱그려진 여러 상품)을 그대로 보내면 서로 다른 수신자에게 완전히 동일한 제목/본문이 나가게 되어 스팸 감지에 더 취약해집니다. 기본 템플릿의 `{{GREETING}}`/`{{CLOSING}}` 자리는 몇 가지 인사말/맺음말 중 하나가 줄마다 자동으로 돌아가며 채워져, 같은 상품명이어도 문구가 조금씩 달라집니다. 예전부터 쓰던 커스텀 템플릿에는 이 토큰이 없어 효과가 없는데, "메일 템플릿" 카드의 **"스팸 방지 기본 템플릿으로 초기화"** 버튼을 누르면 바로 적용됩니다(직접 쓴 문구는 사라지니 필요하면 미리 복사해두세요).

> 이 세 가지는 어디까지나 위험을 줄여주는 장치일 뿐, 구글의 스팸 판정을 100% 피한다고 보장하지는 않습니다. 특히 홍보성 문구가 반복되는 대량 발송이라면 하루 총량을 며칠에 걸쳐 나눠 보내는 것을 권장합니다.

## 참고

- 쿠팡 페이지 구조가 바뀌어도 잘 동작하도록, 특정 CSS 클래스명이 아닌 화면에 보이는 라벨 텍스트("상호/대표자", "사업장 소재지" 등)를 기준으로 값을 찾습니다.
- 저장된 데이터는 기본적으로 이 브라우저(크롬 프로필)의 로컬 저장소에만 보관되며, 외부로 전송되지 않습니다. 위의 "구글 스프레드시트 실시간 연동"을 직접 설정한 경우에만, 본인이 지정한 Apps Script 웹앱 URL로 캡처 데이터가 전송됩니다.
- "판매자 정보" 영역이 화면에 로드되어 있지 않으면 캡처에 실패할 수 있습니다. 이 경우 "배송/교환/반품 안내" 탭을 펼친 뒤 다시 시도하세요. 자동 캡처는 이 탭 클릭도 자동으로 시도합니다.
- 자동 캡처는 쿠팡 서버에 부담을 주지 않도록 한 번에 최대 30개, 상품/키워드 사이에 여유 있는(무작위성이 섞인) 딜레이를 두고 순서대로(동시에 여러 개 열지 않고) 처리합니다. 너무 자주 반복 실행하지 않는 것을 권장합니다.
- **차단 화면을 만나면 이 확장프로그램은 남은 작업을 억지로 계속하지 않고 그 즉시 전체 작업을 멈춥니다.** 감지하는 차단 화면은 두 가지입니다: 쿠팡 자체의 "요청하신 페이지의 사용권한이 없습니다", 그리고 쿠팡이 쓰는 CDN(Akamai)이 요청을 아예 서버까지 보내지 않고 더 앞단에서 막는 "Access Denied / You don't have permission to access..." 화면(주소에 `errors.edgesuite.net`이 보이는 경우)입니다. 팝업에 안내 문구가 뜨면 몇 시간 정도(가능하면 하루) 완전히 쉬었다가, 다시 시작할 때는 이전에 쓰던 개수보다 훨씬 더 작게(키워드 1~2개, 상품 3~5개 수준) 테스트해서 차단이 풀렸는지부터 확인해주세요. 같은 세션에서 바로 재시도하면 또 막힐 가능성이 높습니다.

협업 메일 작성 도구

엑셀(xlsx)을 올리면 이메일/상품명을 읽어서 메일 초안을 자동으로 만듭니다. 실제 발송은 각 줄에서 Gmail 작성창을 열어 직접 "보내기"를 눌러야 합니다 — 실제 전송은 항상 사람이 직접 합니다.

1. 보내는 사람 정보

2. 메일 템플릿

{{PRODUCT}} = 각 줄의 상품명, {{NAME}} = 위에서 입력한 보내는 사람 이름/직책, {{GREETING}}/{{CLOSING}} = 몇 가지 인사말/맺음말 중 하나가 줄마다 자동으로 돌아가며 들어갑니다(스팸 방지용 — 아래 참고) — 모두 자동 치환됩니다. 자유롭게 수정하고 다음에도 재사용하세요 (자동 저장됩니다).

3. 명단 가져오기

엑셀(xlsx) 업로드 또는 구글 스프레드시트 연동 중 하나를 사용하세요. 스프레드시트는 이 확장프로그램의 쿠팡 캡처 동기화 시트와는 별개로, 여기 전용 웹 앱 URL을 따로 지정합니다.
엑셀 업로드: 이 확장프로그램에서 CSV 다운로드한 파일이면 열/이메일 컬럼을 자동으로 찾습니다. 다른 엑셀이면 아래에서 직접 컬럼을 골라주세요.

4. 초안 목록

완료 이메일 상품명 (수정 가능) 작업
엑셀을 업로드하면 여기에 목록이 표시됩니다.

5. 자동 발송 (선택)

정해진 간격으로 아직 "Gmail로 작성하기"를 누르지 않은 항목을 순서대로 열어줍니다. 각 작성창은 화면 앞에 열리고, 지정한 시간만큼 카운트다운하며 — 그 사이에 내용을 직접 수정할 수 있고, 시간이 되면 그 시점 내용 그대로 "보내기"를 대신 눌러줍니다. 언제든 "지금 취소"를 누르면 해당 건은 전송되지 않습니다.
스팸/계정 정지 방지 권장치: 구글은 시간당 발송 한도를 공식적으로 밝히지 않지만, 일반적으로 시간당 20통 이하, 하루 40~100통 이내로 보내는 것이 안전하다고 알려져 있습니다. 아래 "하루 최대 발송 개수"를 채워두면 그 한도에 도달했을 때 자동으로 멈췄다가, 다음날 같은 간격으로 이어서 보냅니다 — 굳이 매일 직접 재시작할 필요가 없습니다.

협업 메일 작성 도구

엑셀(xlsx)을 올리면 이메일/상품명을 읽어서 메일 초안을 자동으로 만듭니다. 실제 발송은 각 줄에서 Gmail 작성창을 열어 직접 "보내기"를 눌러야 합니다 — 실제 전송은 항상 사람이 직접 합니다.

1. 보내는 사람 정보

2. 메일 템플릿

{{PRODUCT}} = 각 줄의 상품명, {{NAME}} = 위에서 입력한 보내는 사람 이름/직책으로 자동 치환됩니다. 자유롭게 수정하고 다음에도 재사용하세요 (자동 저장됩니다).

3. 엑셀 업로드

이 확장프로그램에서 CSV 다운로드한 파일이면 열/이메일 컬럼을 자동으로 찾습니다. 다른 엑셀이면 아래에서 직접 컬럼을 골라주세요.
